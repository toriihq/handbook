# Agentic Coding

## Use AI to write code

As of 2026, we assume 100% of the code to be written by AI. Work to describe the end result, constraints and requirements and work on reviewing the code.

Wherever possible, automate work using AI Agents in the cloud instead of on local machine.

## Build the machine that writes the code

We should shift most of our work from "writing the code that builds the product", to "building the machine that builds the product". In practice, this means automating work using AI agents and trying to remove humans from the loop.

In a perfect world, AI will find a bug, triage it, fix it, test it, get approval for it from another AI Agent, and push the changes directly to production.

AI Agents work best when they have context and access to the right tools. Dedicate a big portion of your work to making sure it can solve the problems instead of saying "I'll just do this one myself".

## A good codebase for humans is a good codebase for agents

AI Agents, and humans, work best when code is standardized. When all APIs are written in the same way, when all components have the same structure. Work to align mis-standardization in the code and make the codebase simpler and cleaner.
